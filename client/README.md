# RealTran デスクトップクライアント

> **English:** [README_EN.md](README_EN.md)

会議に参加する PC で実行します。主な機能は次のとおりです。

- 2 つの音声を取り込みます。
  - **この PC のマイク：** 自分と、会議室にいる人の声
  - **システム音声：** Teams / Zoom / Meet のオンライン参加者の声
- 取り込んだ音声を RealTran サーバーに送ります。文字起こしと翻訳はサーバーで行います。
- 字幕を画面下のバーに表示します。バーは会議アプリより手前に、常に最前面で表示されます。

この PC に GPU は不要です。Python だけあれば動きます。

## 初めて使うとき

1. [python.org](https://www.python.org/downloads/) から Python 3.10 以降をインストールします。
   - **Windows：** インストール時に「Add python.exe to PATH」にチェックを入れてください。
   - **Mac：** python.org のインストーラーを使ってください。字幕バーに必要な Tk ライブラリが含まれています。Homebrew の Python には含まれていません。
2. `RealTran_client.zip` を展開します。この zip はサーバーで `make_client_zip.py` を実行して作ったもので、サーバーのアドレスがすでに入っています。
3. サーバーが起動していることを確認します。

## 起動

- **Windows：** `start_client_lan.bat` をダブルクリックします。PowerShell からは `.\start_client_lan.bat` と入力します。
- **Mac：** ターミナルで `client` フォルダーに移動し、`sh start_client_lan.sh` を実行します。マイクへのアクセスを求められたら許可してください。
- **サーバー PC 自体で使う場合：** `start_client_local.bat` を使います。
- **`start_client.bat` / `.sh`：** SSH トンネル経由で接続する起動スクリプトです。
  - サーバーに OpenSSH Server と鍵認証の設定が必要です。
  - `_lan` 付きの起動スクリプトにはこの設定は不要です。

初回は必要なパッケージのインストールに 1 分ほどかかります。サーバーの自己署名証明書は、クライアントが自動で受け入れます。

字幕バーの一番上の行に状態が表示されます。

```
● 接続中   マイク ▮▮▯▯▯   システム音声 ▮▮▮▯▯
```

誰かが話すと音量バーが動きます。各文の前のラベルは音声の出どころを表しています。

- **ローカル：** マイクの音声
- **オンライン：** システム音声

## 字幕バーの操作

- **ドラッグ（左ボタン）：** 移動できます。位置は記憶されます。
- **マウスホイール：** 一度クリックしてからホイールを回すと、背景の透明度を変えられます。
- **右クリック：** 設定メニューを開きます。設定は `client_settings.json` に保存されます。メニューの項目は次のとおりです。
  - **表示言語 / 界面语言 / Language：** メニューの表示言語を選びます。最初は日本語です。
  - **中国語を表示 / 日本語を表示 / 英語を表示：** 表示する訳文を選びます。複数選べます。
  - **原文も表示：** 訳文の下に原文をグレーで表示します。
  - **背景の透明度：** 不透明から完全に透明（縁取り付きの文字だけ）まで選べます。
  - **表示する文の数**、**文字の大きさ**、**幅**
  - **収音：このPCのマイク / システム音声：** それぞれ個別にオフにできます。
  - **⏺ 議事録の記録を開始 / ⏹ 記録を終了して議事録を作成：** 開始した時点からの自分の発言が保存されます。終了するとサーバーが議事録を作成します。
  - **議事録を開く（ブラウザ）**

マイク・システム音声・字幕・記録は、この PC だけのものです。同じサーバーを使う他の人には表示されません。

## 使用するデバイス

- **マイク：**
  - Windows の既定のマイクに自動で合わせます。ヘッドセットをつなぐと数秒で切り替わります。
  - 使用中のデバイス名はメニューに表示されます。
  - 特定のマイクに固定したい場合は `--mic-device <名前の一部>` を付けて起動してください。
- **システム音声：**
  - すべての再生デバイスの音をまとめて取り込みます。Teams をヘッドセットで、ブラウザをスピーカーで聞いている場合も、両方とも取り込まれます。
  - デバイスの一覧は `start_client_lan.bat --list-devices` で確認できます。
- **ヘッドセットではなくスピーカーを使う場合：**
  - オンライン参加者の声がマイクにも入り、同じ文が 2 回認識されてしまいます。
  - これを防ぐため、システム音声に発言がある間はマイクを自動でミュートします。
  - ヘッドセットを使う場合は、`--no-duck` でこの機能をオフにできます。

## Mac

- **システム音声：** macOS は仮想オーディオデバイスがないと再生中の音を録音できません。次の手順で設定してください。
  1. 無料の **BlackHole 2ch** をインストールします。
  2. 「Audio MIDI 設定」で、スピーカー / ヘッドホンと BlackHole をまとめた「複数出力装置」を作ります。
  3. それをシステムの出力に設定します。

  BlackHole はクライアントが自動で見つけます。BlackHole がない場合は、マイクだけを取り込みます。
- **透明度：** macOS では文字と背景を別の層に分けられないため、背景と一緒に文字も薄くなります。
- **右クリック：** 2 本指でクリックするか、Control キーを押しながらクリックします。
- **全画面の会議：** 全画面表示の Zoom や Teams の上には字幕バーを表示できません。ウィンドウ表示で使ってください。

## オプション

| オプション | 内容 |
|---|---|
| `--list-devices` | マイクとスピーカーの一覧を表示する |
| `--test-audio` | すべてのスピーカーとマイクを 5 秒間録音し、音が届いているかを表示する。実行中は何か音を再生してください |
| `--mic-device 名前` | 指定したマイクを使う（名前の一部で可） |
| `--system-device 名前` | システム音声の代わりにこの入力デバイスを使う（Mac では BlackHole を自動で選ぶ） |
| `--no-duck` | ヘッドセット使用時：オンライン参加者の発言中もマイクをミュートしない |
| `--server wss://アドレス:8765` | 別のサーバーに接続する |
